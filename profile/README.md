# JJYDXFS Lab

A small independent lab for curiosity-driven building.

We make tools, prototypes, notes, and experiments around data, AI, software, and creative technology. Some projects are polished; many are intentionally exploratory.

Principles:

- Build what is useful, interesting, or delightful.
- Keep experiments small enough to learn from.
- Prefer clear artifacts over vague promises.
- Respect privacy, attribution, and safety boundaries.
